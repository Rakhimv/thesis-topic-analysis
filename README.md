# Анализ тем выпускных работ (thesis-topic-analysis)

## Обзор
Проект предназначен для анализа тем выпускных квалификационных работ (ВКР) из Excel-файла. Позволяет выявить распределения, тренды и взаимосвязи по годам, факультетам, кафедрам и научным руководителям.

## Структура данных
Исходный Excel-файл содержит следующие столбцы:

| Столбец | Описание |
|---------|----------|
| Graduation | Год выпуска |
| Title_ru | Название работы (рус.) |
| Title_en | Название работы (англ.) |
| Level | Уровень образования |
| Faculty | Факультет |
| Speciality | Специальность / направление |
| Advisor | Научный руководитель |
| Position | Должность руководителя |
| Department | Кафедра |

## Задачи

### Задача 1: Распределение работ по тематикам (`Task1.py`)
Анализ распределения ВКР по тематическим категориям.

### Задача 2: Распределение тематик по годам (`Task2.py`)
Анализ того, как тематики работ меняются с течением времени.

### Задача 3: Облака слов (`Task3.py`)
Построение облаков слов для визуального представления ключевых понятий:
- Для каждого научного руководителя
- Для каждой кафедры

### Задача 4: Выделение преподавателей по тематикам (`Task4.py`)
Идентификация и группировка научных руководителей на основе их тематической специализации.

### Задача 5: Связь между тематиками и кафедрами (`Task5.py`)
Исследование взаимосвязей между темами ВКР и кафедрами, на которых они выполнялись.

## Дополнительные исследования:

### Исследование 1: Анализ нагруженности преподавателей (`1additional_research.py`)
Проанализировать для каждого преподавателя количество им курируемых работ и вывести 10 самых загруженных.

### Исследование 2: Определить для каждого преподавателя основную тематику (`2additional_research.py`)
Определить для каждого научного руководителя его основную тематическую специализацию и рассчитать долю работ по этой теме.

## Поисковая система (`search.py` + `app.py`)

Веб-приложение для поиска научных руководителей по тематике или ключевым словам.

### Алгоритм ранжирования:

| Совпадение | Баллы |
|------------|-------|
| Совпадение с категорией запроса | +15 за каждую работу |
| Совпадение с ключевыми словами в названии | +10 за каждое совпадение |

## Вспомогательные файлы

### `exp.py`

Экспериментальный скрипт для анализа работ, попавших в категорию "Прочее" (не классифицированных). Выводит список таких работ и проверяет, какие ключевые слова из словаря отсутствуют.
